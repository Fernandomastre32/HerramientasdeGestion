# HerramientasdeGestion

## Descripción

Este repositorio fue creado como parte de la práctica "Herramientas de gestión de proyectos y de recursos: repositorios de código y documentación".

El objetivo es aprender el uso de GitHub como herramienta de colaboración, control de versiones y organización de proyectos mediante la creación y administración de un repositorio compartido.
